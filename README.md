# ShopSphere

A responsive e-commerce frontend website built using HTML, CSS, and JavaScript, featuring product browsing, authentication pages, shopping cart, wishlist, checkout, and user profile interfaces.

## 🚀 Features

* Responsive e-commerce user interface
* Product listing and product details pages
* Category-based product browsing
* Shopping cart interface
* Wishlist functionality
* Login and signup pages
* User profile page
* Checkout and order-success pages
* 404 error page
* Interactive UI using JavaScript
* Responsive design for desktop and mobile screens

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

## 💻 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Priyu-code14/ShopSphere.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation or backend setup is required.

## 🎯 Project Objective

ShopSphere was developed as a frontend project to practice building a multi-page e-commerce website using HTML, CSS, and JavaScript while focusing on responsive design, reusable UI components, and interactive user experiences.
